# Trailblazer

Personal trail-training platform on Cloudflare (see README.md for architecture, setup, migrations and infra).

## Git: never push to `main`

All changes go through a branch and a pull request. Follow the `git-workflow` skill (`.claude/skills/git-workflow/SKILL.md`)
for branch naming, commits, verification and the PR description template. Never commit or push to `main`, and don't merge
PRs unless asked.
